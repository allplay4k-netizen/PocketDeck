# PocketDeck
Open-source ESP32 handheld device project

## Main Goal

Create an open-source ESP32 handheld device inspired by projects like Meshtastic and LoRa-based devices.

The goal is to create a customizable and expandable portable device with features added over time. The exact hardware and features are still being planned.

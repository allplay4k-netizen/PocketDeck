# PocketDeck

An open-source handheld device built around the ideaspark ESP32 1.14" TFT development board. The goal is to create a customizable, expandable device inspired by projects such as Meshtastic, while remaining simple enough for anyone to build, modify, and improve.

# Project Status

**Current Stage:** Firmware Development

The current focus is developing the firmware using the base hardware before purchasing additional components.

## Development Board

- ideaspark® ESP32 Development Board Integrated 1.14 inch ST7789 135x240 TFT LCD Display (Solder PIN)

The goal is to build and test as many features as possible using only this board. This allows the project to determine which hardware is actually necessary instead of purchasing parts that may never be used.
